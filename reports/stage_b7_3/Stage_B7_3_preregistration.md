# Stage B7.3 Preregistration

## Title

C12 Reconnection and H24 Topology Falsification Audit.

## Status

This preregistration is written after B7.2g execution and after the follow-up clarification from Luke, C.A.T., and Marcel about the H24 168-edge topology.

## Background

B7.2e-g narrowed the endpoint-free C boundary.

The repeated result is not a single-factor explanation. Receiver-side assignment, magnitude-sensitive separation, and standpoint/inversion sensitivity recur as coupled components of the same endpoint-free correspondence boundary.

The B7.2 sequence also left the endpoint-adjacent O1/O2 reference as the strongest upper-bound control. Therefore B7.3 does not treat C12 as confirmed by B7.2. It asks whether a frozen endpoint-free C representation has incremental topology-specific C12/H24 readout value.

Luke's H24 proposal is now operational enough to include as a topology arm. The canonical Luke/H24 carrier for this audit is the 168-edge minimum factorisation-suite topology generated by the deterministic H24 construction. The 216-edge Kuramoto-loaded stitched topology is not treated as equivalent to the canonical carrier. It is included only as a derived secondary arm after explicit edge-set hashing and difference accounting.

## Central Question

Does C12 or canonical H24 topology add reproducible information beyond the compact endpoint-free receiver/magnitude/standpoint C representations identified in B7.2e-g?

## Primary Design

B7.3 freezes candidate C representations first, then compares topology readouts.

The primary quantity is incremental topology gain:

```text
Delta_topology = performance(C_representation + topology)
                 - performance(C_representation + no-topology baseline)
```

This prevents a positive result from being read as C12-specific when it is only a property of the event schedule or representation.

## Decision Rules

### C12 Incremental Gain

Supported if `c12_1_2` improves over `no_topology_baseline`, `c8_1`, `c12_reversed`, and `c12_side_broken` for the same C representation by positive effect size and by the preregistered empirical p-value threshold.

### H24 168 Incremental Gain

Supported if `h24_minimum_factorisation_suite_168` improves over `no_topology_baseline`, `h24_effective_ring_edges_144`, and `h24_degree_matched_null` by positive effect size and by the preregistered empirical p-value threshold.

### H24 216 Difference

Supported if `h24_c8_stitched_derived_216` differs from `h24_minimum_factorisation_suite_168` by at least `0.005` in mean bounded differentiated recovery for the same C representation.

### Coupled C Bridge

Supported if `receiver_standpoint_magnitude_c` outperforms `scalar_c`, `receiver_only_c`, `magnitude_only_c`, and `receiver_magnitude_c` on the strongest topology-specific endpoint.

### Endpoint Upper Bound

Supported if `endpoint_o1o2_reference` remains stronger than every endpoint-free C representation.

## Fixed Settings

- event quantile: 0.75

- random controls per representation/topology: 80
- degree null runs: 80
- p-value threshold: 0.05
- seed: 73073

## Interpretation Boundary

B7.3 is a falsification and reconnection audit. It does not treat C12 or H24 as confirmed by construction.

A positive result requires incremental topology-specific gain beyond the frozen endpoint-free representation and beyond topology controls.

A negative result does not refute the ontology. It means the current operational C representation and the current C12/H24 carriers do not yet reconnect under this audit.
