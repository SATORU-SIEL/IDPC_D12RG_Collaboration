# Stage B7.1 Collaboration-Facing Plan

Status: preregistered before Stage B7.1 execution. This records the plan shared with collaborators in prose form, alongside the technical preregistration.

## Core Framing

B7.1 is the next step after B6. It is not another expansion of the interpretive architecture. It is a preregistered discrimination audit.

The purpose is to freeze the key B6 findings in advance and test them out-of-sample with stronger controls.

The important point is that B6 did not stop at "C-mediated intersection access survives." In B6W/B6Z, the result went further:

- C is not freely substitutable.
- C is phase-sensitive.

Therefore, B7.1 should not merely test whether adding a C-like mediator improves access. It should test whether the specific C construction is necessary, non-substitutable, and phase-sensitive after conditioning on the available histories of A and B.

## Central Question

Does true C retain out-of-sample intersection-access or operator-selection information after conditioning on the complete available histories of A and B?

More specifically, does true C-mediated intersection access survive against:

- expressive nonlinear A-B-only models
- lag-matched A-B-only models
- matched fake-C constructions
- phase-displaced C controls
- objectification-style C scores
- held-out replication splits

## Primary Hypothesis

True C-mediated intersection access is not merely produced by inserting any C-like mediator. It should require the specific C construction, and it should degrade under matched fake-C substitution and preregistered phase displacement.

## Endpoint Boundary

The primary endpoint should not be C12.

The primary endpoint should be intersection_access_effect, with operator_selection_advantage as a secondary primary-compatible endpoint.

C12 should not be primary because B6 did not primarily isolate C12 optimization. B6 isolated a phase-sensitive C-mediated intersection-access condition.

## B6-Supported Regime Definition

A regime should count as B6-supported only if all three criteria are fixed in advance and met:

1. C-necessary: no-C direct A-B access fails, while C-mediated access survives.
2. Non-substitutable: true C outperforms matched fake-C controls.
3. Phase-sensitive: preregistered phase displacement reduces or collapses access.

In the B6 exploration, the overlap of C-necessary, non-substitutable, and phase-sensitive regimes was 11 / 24. In B7.1, this definition should be fixed before execution and not altered after inspecting outcomes.

The strongest required control is whether C retains information after conditioning on the complete available histories of A and B.

## Success Criteria

B7.1 should count as supported only if all of the following hold on held-out data:

1. True C-mediated access outperforms the best A/B-history-only control.
2. True C-mediated access outperforms matched fake-C controls.
3. True C-mediated access outperforms phase-displaced C controls.
4. The collapse profile is reproducible out-of-sample.
5. True C remains below oracle.

The key point is not simply that C helps. The key point is that the specific C construction is necessary, not freely substitutable, and phase-sensitive.

## C12 Secondary Module

C12 can be included in B7.1, but it should not be the primary endpoint. It should be treated as a prespecified secondary topology-readout module.

The C12 module is:

B7.1-C12: Intersection-Conditioned C12 Readout Module.

The C12 question should be:

Does C12 stabilization concentrate prospectively in regimes that are simultaneously C-necessary, non-substitutable, and phase-sensitive?

The C12 module should not test whether C optimizes C12 directly. It should test whether C12 acts as a downstream topology-readout surface for the phase-sensitive C-mediated intersection-access condition.

## Preregistered Statement

B7.1 tests whether the B6 exploratory intersection-access signal survives preregistered out-of-sample discrimination against complete A/B-history models, matched fake-C controls, and phase-displaced C controls.

GMR72/RG4x5 angular response and C12 topology readout are included as prespecified secondary modules.

The central claim is not that C improves C12, and not that C is a recursive self-improving intelligence state.

The central claim to be tested is that true C-mediated intersection access requires the specific C construction, is not freely substitutable, is phase-sensitive, and retains information beyond complete A/B-history controls.
