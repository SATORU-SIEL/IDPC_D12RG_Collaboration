Dear Luke, Marcel, C.A.T., Tom, Chris, all,

After the B7.5 proposal, Luke added an important point that cuts across B7.4g and B7.5.

The B7.5 plan itself started from the boundary already clarified after B7.4g: the narrow cyclotomic + x3 decomposition preserves the survivor structure, while broad completion dilutes the readout carrier.

Luke's additional point is that broad completion should not simply be discarded as unsupported. It may still contain a fractional / cyclotomic convergence signature, even if it is not yet sufficient as a readout carrier.

In particular, Luke pointed to the B7.4g broad group-completion proxy precision of 0.25.

If that is an exact 1/4 signature, it may indicate that four simultaneous double-quadratic cyclotomic roots are being represented.

He also suggested looking not only for 1/M fractions, but for integer-fractional values such as 0.5, 0.333333, 0.25, 0.2, 0.166666, and possible N/M signatures with N > 1.

He also framed ring edges as possible `(x+1)` or `(x-1)` multipliers, so that ring sharing / edge sharing may correspond to cyclotomic polynomial arithmetic, or to simultaneous solutions of multiple cyclotomic 2ODEs.

I therefore propose keeping the central B7.5 question unchanged, but adding a secondary diagnostic.

The central B7.5 question remains:

Is the surviving structure reducible to relation(A,B), is it better described as a reverse-dominant C->AB condition, or does it require a self-consistent AB<->C condition?

The updated B7.5 would have two layers.

Layer 1: Relation / Condition Audit

The main audit compares:

- endpoint / direct relation-only;
- receiver / standpoint relation-only;
- forward-only AB->C;
- reverse-only C->AB;
- self-consistent AB<->C.

Each arm would be compared on:

- C12 readout;
- effect against no-topology;
- reversed C12 / side-broken C12 / shuffled C12 controls;
- neighboring C10/C11/C13/C14 controls;
- agreement with the registered survivor set P10/P5/P21/P15;
- consistency with the B7.4g cyclotomic + x3 decomposition;
- held-out / leave-one-session robustness;
- dilution under broadening;
- fraction explained by relation-only;
- fraction explained by reverse-only;
- increment added by self-consistency.

The decision boundary remains explicit.

If receiver/standpoint relation-only explains the C12 / survivor structure as well as the self-consistent condition, B7.5 should conclude toward a refined receiver/standpoint relation(A,B).

If reverse-only matches or exceeds self-consistency, B7.5 should conclude toward a reverse-dominant condition rather than overstating AB<->C.

If self-consistent AB<->C exceeds relation-only and reverse-only, and best preserves the C12 / survivor / held-out structure, then the directed-correspondence-condition interpretation becomes stronger.

Layer 2: Fractional / Cyclotomic Diagnostic

This is not the primary B7.5 decision rule. It is a secondary diagnostic added in response to Luke's mathematical point.

For each arm, it would check whether:

- overlap precision / recall / Jaccard / dilution ratios are close to exact integer fractions;
- only 1/M fractions appear, or whether N/M with N > 1 appears;
- values such as 0.5, 1/3, 1/4, 1/5, or 1/6 appear stably;
- broad completion arms show fractional signatures while still diluting the readout carrier;
- survivor-centered arms preserve both fractional signatures and C12 readout;
- ring-sharing / edge-sharing proxies align with the fractional signature.

This update lets B7.5 keep relation vs condition as the primary audit, while also tracking the fractional / cyclotomic convergence signal Luke pointed out.

The integrated boundary would be:

Broad completion remains insufficient as a readout carrier, but may still contain a fractional / cyclotomic convergence signature.

So B7.5 would not adopt broad completion as the carrier. It would treat it as a diagnostic target for possible fractional structure.

If this framing looks right, I will preregister B7.5 in this updated form and execute it.
