Dear Luke, Marcel, C.A.T., Thomas, Chris, all,

I have revised the B7.2 plan to incorporate the two main feedback points before preregistration and execution.

The primary B7.2 question remains the O1/O2 causal-validity and control-hierarchy audit.

The purpose is to determine whether the B7.1/B7.1a boundary is explained by ordinary A/B history, by a causally valid past-only A/B-derived operator estimate, or by endpoint-adjacent O1/O2 operator-proxy information.

The frozen hierarchy will be:

1. strict past A/B only;
2. expanded past A/B only;
3. causally valid past-only operator estimator;
4. lag/horizon-separated O1/O2 proxy summaries;
5. endpoint-adjacent O1/O2 operator proxy;
6. true C-mediated access.

The primary success criterion will not require true C to beat the endpoint-adjacent O1/O2 proxy. B7.1/B7.1a already showed that this proxy can dominate true C.

Instead, B7.2 will ask whether true C beats the causally valid controls after endpoint-adjacent O1/O2 information is removed.

So the key interpretation will be:

- If true C beats strict and expanded past A/B, but not the causally valid past-only operator estimator, then B7.1a only rules out simple A/B history.
- If true C beats the causally valid estimator, but not lag/horizon-separated O1/O2, then the remaining boundary is temporally separated O1/O2 information.
- If true C beats the causally valid estimator and lag/horizon-separated O1/O2, but not the endpoint-adjacent O1/O2 proxy, then B7.1's failure is best interpreted as an endpoint-adjacent proxy boundary, not simple A/B-history reducibility.
- If true C also beats endpoint-adjacent O1/O2, then the current C representation exceeds the full tested hierarchy.

I am also keeping Marcel's constraint explicit:

C12 remains paused as a confirmatory topology module during B7.2.

B7.2 may say whether a future C12 reconnection test has become better motivated, but it must not use C12 stabilization to rescue a failed B7.2 primary result.

The mediation/closure interpretation only becomes stronger if true C remains frozen-B6 supported, non-substitutable, phase-sensitive, held-out stable, and not explained by causally valid A/B-derived operator estimates.
